# Privacy Policy

Last updated: 2026-08-28

Arabic Word Production is an open-source Skill and plugin package. The project does not operate a server, create user accounts, collect analytics, or receive a copy of your files through a project-controlled service.

## Processing boundary

When the Skill runs, the host application and the environment selected by the user control file handling, retention, permissions, and any account-level settings. This project cannot override those host controls. Review the host application's privacy terms and workspace settings before processing confidential material.

## Your files and outputs

Use only content you are authorized to process. Save generated `DOCX`, reports, renders, and temporary artifacts only where you intend them to remain. You are responsible for reviewing output before sharing it and for applying any organization-specific retention, confidentiality, or backup requirements.

## Public project contributions

The GitHub repository is public. Do not submit real client documents, raw conversations, personal data, credentials, or confidential screenshots. Use synthetic or fully sanitized fixtures only. The [privacy and test-data policy](https://github.com/Bannovich/arabic-word-production/blob/main/docs/privacy-and-test-data.md) explains the required sanitization standard.

## Contact

For a repository concern, use the project's [GitHub Issues](https://github.com/Bannovich/arabic-word-production/issues) without including sensitive information.
