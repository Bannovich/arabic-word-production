# Roadmap

The roadmap is evidence-driven and has no promised dates. Priorities may change when reproducible defects expose a higher-risk gap.

## `v0.1.x` — establish the public baseline

- Publish the canonical Skill and skills-only plugin package.
- Maintain privacy-safe Issue forms and continuous quality checks.
- Collect sanitized independent usage reports.
- Fix reproducible defects without broadening unsupported claims.

## `v0.2.x` — deepen compatibility evidence

- Expand the compatibility matrix across named Word Desktop builds and operating systems.
- Add more synthetic fixtures for mixed Arabic-English runs, nested tables, headers, footers, and section changes.
- Improve visual review evidence and accessibility checks.
- Document a repeatable contributor-run Word Desktop protocol.

## `v0.3.x` — complex objects and layout

- Evaluate charts, equations, shapes, embedded objects, tracked changes, and advanced field behavior.
- Improve wide-table layout decisions and mixed-orientation recovery.
- Measure performance by route and fixture complexity.

## Future release candidates

- Explore additional compatible Agent Skills hosts based on verified behavior.
- Consider universal Plugins Directory submission only after metadata, privacy, support, and review requirements are met.
- Consider `v1.0.0` only after repeatable installation, stable contribution governance, a maintained compatibility matrix, and sufficient independent evidence demonstrate maturity.

Suggestions belong in the improvement Issue form. A roadmap entry is an investigation target, not a compatibility promise.
