# Support

Arabic Word Production is a community open-source project. Support is best effort and has no service-level agreement.

## Before asking for help

1. Read the English or Arabic README and the Skill's route selection.
2. Use the latest release.
3. Run the structural auditor and keep its non-sensitive summary.
4. Search existing Issues for the same error ID or symptom.
5. Reproduce the problem with synthetic or sanitized content.

## Where to ask

- Use GitHub Issues for reproducible, sanitized defects and improvement requests.
- Use GitHub Discussions if enabled later for general questions that do not represent defects.
- Use private vulnerability reporting for security matters as described in [SECURITY.md](SECURITY.md).

Do not send confidential files through public Issues, Pull Requests, or comments. The project cannot provide private document-review services through the public repository.

## Scope boundaries

The project can help with its instructions, scripts, OOXML invariants, test fixtures, and documented routes. It cannot promise:

- identical rendering across every Word version or office suite;
- recovery of corrupted or password-protected documents;
- correctness of business, legal, medical, financial, or client content;
- support for unlicensed software or unauthorized systems;
- a fixed completion or response time.

For an urgent production document, keep a recoverable copy, validate the exact final file in the target Word Desktop environment, and use an appropriate professional reviewer for the document's subject matter.
