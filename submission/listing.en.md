# Arabic Word Production

Short description: Audited Arabic Word files

Support URL: https://github.com/Bannovich/arabic-word-production/issues

Arabic Word Production creates, repairs, and structurally audits Arabic-first and bilingual Arabic-English `DOCX` files. It applies explicit paragraph, run, table, and section direction controls so that right alignment is not mistaken for native `RTL` behavior.

Use it to create a Word document from supplied content, repair a mixed-direction document, inspect structural `RTL` properties, evaluate wide tables for landscape layout, or report the validation surface honestly. Results distinguish between built, structurally audited, rendered and inspected, and Word Desktop verified files.

The initial directory candidate is skills-only. It has no MCP tools, external account connection, telemetry, or project-operated data service. Compatibility can vary by Word version, font, operating system, renderer, and office suite. Word Desktop verification is claimed only when the exact file was opened and checked there.
