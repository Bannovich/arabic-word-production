# Initial directory candidate

This is the initial skills-only directory candidate for Arabic Word Production.

- Packages the open-source `arabic-word-production` Skill.
- Adds directory-facing metadata, public policy pages, reviewer cases, and local contract validation.
- Does not add MCP tools, authentication, telemetry, commerce, or a project-operated data service.
- Keeps the source code free under Apache-2.0.
- Describes Word validation evidence precisely rather than asserting universal compatibility.
