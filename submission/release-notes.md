# 0.1.1 identity update

This skills-only update gives the plugin the shorter user-facing name **Arabic DOCX RTL** while preserving the stable `arabic-word-production` package and Skill identifiers.

- Adds separate square Directory and Composer assets based on a document, explicit left-pointing RTL arrow, and validation check.
- Updates the interface palette to `#4E249F` while retaining the existing Arabic Word production workflow.
- Does not add MCP tools, authentication, telemetry, commerce, or a project-operated data service.
- Keeps the source code free under Apache-2.0.
- Does not change the validation claims or assert universal Word compatibility.
