# Local continuation protocol

Read `CONTINUATION.md` before continuing work in this repository. Verify its checkpoint against the working tree; preserve unfinished changes.

Update `CONTINUATION.md` after each completed milestone and before handing work back. Record changes, actual verification results, pending work, and the exact next action. Distinguish tested results from historical reports. Do not mark unfinished work complete.

Keep checkpoints on disk as work proceeds. A final response is not a substitute for saving the checkpoint. Never include credentials, identity documents, private conversations, or account billing data in tracked files.

Keep the package identifier `arabic-word-production` and Apache-2.0 license. The approved display name is `Arabic DOCX RTL` and the selected visual is concept 2. Consult `assets/BRANDING.md` before changing identity assets.

Do not create recurring follow-ups: the maintainer cancelled the five-hour monitor. Final OpenAI review submission or publication requires the maintainer's explicit confirmation at the time of action. Check current authorization before external integration; preparing local changes does not imply publication.
